## 📝 Maintenance Guidelines

### When to Update Documentation:

1. **New Edge Function Added**:
   - Update `API_REFERENCE.md`
   - Update edge function count in `MASTER_SYSTEM_GUIDE.md`
   - Add to relevant section in `DEVELOPMENT_GUIDE.md`

2. **System Architecture Change**:
   - Update `MASTER_SYSTEM_GUIDE.md` Section 1
   - Update relevant patterns in `DEVELOPMENT_GUIDE.md`
   - Add to version history

3. **New Feature/Roadmap Item**:
   - Update `OPERATIONS_GUIDE.md` Section 2 or 3
   - Update status indicators
   - Update implementation history if completed

4. **Error Resolved**:
   - Update `MASTER_ERRORS_TO_FIX.md`
   - Change status to RESOLVED
   - Add resolution details

5. **Deployment Process Change**:
   - Update `DEPLOYMENT_GUIDE.md`
   - Update version history
   - Test new procedures

### Update Process:
1. Identify affected documents using Cross-Reference Matrix
2. Update primary document first
3. Update related cross-references
4. Update version history
5. Verify navigation links still work
